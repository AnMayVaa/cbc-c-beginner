## 01: พื้นฐานการคิดแบบโปรแกรมเมอร์ (Fundamentals)

### การเขียนโปรแกรมคืออะไร?
คอมพิวเตอร์ทำงานเร็วมาก แต่มัน "คิดเองไม่เป็น" การเขียนโปรแกรมคือการนำ **"ตรรกะของมนุษย์ (Human Logic)"** มาแปลเป็น **"คำสั่งที่เครื่องจักรเข้าใจ (Machine Instructions)"** 

### ทำไมต้องภาษา C?
ภาษา C คือรากฐานของสถาปัตยกรรมซอฟต์แวร์สมัยใหม่ การเรียน C คือการเรียนรู้ว่า "คอมพิวเตอร์จัดสรรหน่วยความจำและทำงานจริงๆ อย่างไร" ไม่ใช่แค่การท่องจำคำสั่ง

### โครงสร้างของโปรแกรม (The `main` Entry Point)
ทุกโปรแกรมต้องมี "จุดเริ่มต้น" เสมอ ในภาษา C คอมพิวเตอร์จะวิ่งตามหาฟังก์ชันที่ชื่อว่า `main()` ก่อนเป็นอันดับแรก 

```c
#include <stdio.h> // นำเข้าเครื่องมือพื้นฐาน (Input/Output)

int main() {
    // อัลกอริทึมและการทำงานหลักจะอยู่ที่นี่
    printf("Hello Logic!\n");
    return 0; // ส่งสัญญาณบอกระบบว่าโปรแกรมจบสมบูรณ์
}
```

## 02: ข้อมูลและหน่วยความจำ (Data Types & Variables)

### ตัวแปร (Variables): กล่องเก็บของในโลกดิจิทัล
ก่อนจะคำนวณอะไรได้ เราต้องมี "พื้นที่" สำหรับทดเลข ตัวแปรคือการสั่งให้คอมพิวเตอร์ "จองพื้นที่ใน RAM" เพื่อรอรับข้อมูล 

### ทำไมต้องแบ่งชนิดข้อมูล (Data Types)?
คอมพิวเตอร์มองทุกอย่างเป็นเลขฐานสอง (0 และ 1) การที่เราบอกว่ากล่องนี้เป็น `int` (จำนวนเต็ม) หรือ `float` (ทศนิยม) คือการบอกคอมพิวเตอร์ว่า **"ให้แปลความหมายเลข 0 และ 1 ในกล่องนี้อย่างไร"**

- `int` : สำหรับข้อมูลที่นับเป็นชิ้นๆ ไม่มีการแตกย่อย (เช่น จำนวนคน, อายุ)
- `float` : สำหรับข้อมูลที่มีความต่อเนื่อง (เช่น น้ำหนัก, ส่วนสูง, อุณหภูมิ)
- `char` : สำหรับสัญลักษณ์ 1 ตัวอักษร

### อัลกอริทึมการคำนวณ (Processing)
แนวคิดหลักของการเขียนโปรแกรมคือ `Input -> Process -> Output`
เราไม่ควรแสดงผลลัพธ์จากการคำนวณสดๆ แต่ควรเก็บผลลัพธ์ไว้ในตัวแปรใหม่ก่อนเสมอ เพื่อนำไปต่อยอดอัลกอริทึมในอนาคต

## 03: การควบคุมทิศทาง (Flow Control)

### จากเส้นตรง สู่การตัดสินใจ (Branching)
ปกติโปรแกรมจะทำงานจากบรรทัดบนลงล่าง แต่โลกความเป็นจริงมี "เงื่อนไข" (Conditions)
`if-else` คือกลไกที่ทำให้โปรแกรม "คิดและเลือกทางเดิน" ได้ตามข้อมูลที่เปลี่ยนไป (Dynamic Execution)

### อัลกอริทึมการกรองข้อมูล (Filtering Logic)
การใช้ `if -> else if -> else` คือการกรองข้อมูลจาก "เงื่อนไขที่เฉพาะเจาะจงที่สุด" ไปหา "เงื่อนไขทั่วไป" 
(เช่น การตัดเกรด ต้องเช็คคะแนนที่สูงที่สุด A ก่อนไล่ลงมา F)

### การทำซ้ำ (Loops): พลังที่แท้จริงของคอมพิวเตอร์
มนุษย์เบื่อหน่ายที่จะทำอะไรซ้ำๆ แต่คอมพิวเตอร์ทำซ้ำได้เป็นล้านครั้งใน 1 วินาที!
- **While Loop:** ทำซ้ำจนกว่า "เงื่อนไขบางอย่างจะพังทลาย" (เหมาะกับสถานการณ์ที่ไม่รู้จำนวนรอบชัดเจน)
- **For Loop:** ทำซ้ำแบบ "กำหนดจุดเริ่มต้นและจุดสิ้นสุดชัดเจน" (เหมาะกับการนับจำนวนรอบ)

## 04: การจัดการข้อมูลชุดใหญ่ และ การแบ่งโค้ด (Arrays & Functions)

### Arrays: พื้นที่หน่วยความจำแบบต่อเนื่อง
เมื่อเรามีข้อมูลประเภทเดียวกัน 1,000 ตัว การสร้างตัวแปร 1,000 ชื่อคือหายนะทางโครงสร้าง
`Array` คือการจองพื้นที่ใน RAM แบบ "เรียงติดกัน" (Contiguous Memory) ทำให้เราสามารถใช้ `Loop` วิ่งไปจัดการข้อมูลตั้งแต่ช่องแรก (Index 0) ยันช่องสุดท้ายได้อย่างมีประสิทธิภาพ!

### ฟังก์ชัน (Functions): การสร้าง "กล่องดำ" (Black Box)
อัลกอริทึมที่ดี ไม่ควรถูกเขียนกองรวมกันใน `main()` จนอ่านไม่ออก
เราใช้ Function เพื่อแบ่งโค้ดเป็น "โมดูลย่อยๆ" ที่มีหน้าที่เดียว (Single Responsibility)

### แนวคิด Input / Output ของฟังก์ชัน
- **Parameters (Input):** วัตถุดิบที่ส่งเข้าไปในกล่องดำ
- **Process:** การคำนวณภายในที่โปรแกรมหลักไม่ต้องรู้ว่าทำอย่างไร
- **Return (Output):** ผลลัพธ์ที่ส่งกลับออกมาให้โปรแกรมหลักใช้งานต่อ
