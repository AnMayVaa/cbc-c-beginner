## 📖 บทที่ 1: C Fundamentals

### 🎯 จุดประสงค์
ให้นักเรียนเข้าใจโครงสร้างพื้นฐานของภาษา C สามารถสั่งพิมพ์ข้อความออกทางหน้าจอได้ และสามารถรับข้อมูลเบื้องต้นจากผู้ใช้ได้

### 💡 สิ่งที่ต้องเน้น (Key Points)
*   **โครงสร้างบังคับ**: ทุกโปรแกรมต้องมี `#include <stdio.h>` และฟังก์ชัน `int main() { ... return 0; }` โค้ดจะเริ่มทำงานใน block นี้เสมอ
*   **Semicolon (`;`)**: จบประโยคคำสั่งทุกครั้ง ต้องมี `;` เสมอ (เปรียบเหมือนจุด Full stop ในภาษาอังกฤษ)
*   **ขึ้นบรรทัดใหม่**: `printf` ไม่ขึ้นบรรทัดใหม่ให้เอง ต้องใส่ `\n` ไปด้วย

### ⚠️ ข้อผิดพลาดที่มือใหม่มักเจอ (Common Pitfalls)
*   **ลืม `&` ใน `scanf`**: เช่น เขียน `scanf("%d", age);` โปรแกรมจะพัง (Segmentation Fault) ตอนรัน ต้องเน้นว่าต้องเป็น `&age` (ยกเว้นตอนรับ string/array ซึ่งยังไม่สอนในคลาสนี้)
*   **ใส่ `\n` หรือเว้นวรรคแปลกๆ ใน `scanf`**: เช่น `scanf("%d\n", &age);` แบบนี้โปรแกรมจะค้างรอรับค่าตัวต่อไป อธิบายเด็กๆ ว่าใน `scanf` ใส่แค่ `%d` พอ
*   **ลืม Semicolon**: Error สุดฮิต! สอนให้นักเรียนสังเกตบรรทัดที่ Compiler แจ้ง Error (มักจะแจ้งที่บรรทัดถัดจากที่ลืมใส่)

### 💬 ทริคการสอน
ตอนให้ทำแบบฝึกหัดคำนวณอายุ อาจจะบอกให้นักเรียนระวังเรื่องปีเกิด ว่าโปรแกรมเรารับเป็น ค.ศ. หรือ พ.ศ. (แนะนำให้รับเป็น ค.ศ. จะลบเลขง่ายกว่า)

## 📖 บทที่ 2: Data Types and Math

### 🎯 จุดประสงค์
ให้นักเรียนรู้จักการจองพื้นที่ในหน่วยความจำ (ตัวแปร) และชนิดข้อมูลพื้นฐาน รวมถึงการบวก ลบ คูณ หาร และหาเศษ (Modulus)

### 💡 สิ่งที่ต้องเน้น (Key Points)
*   **Format Specifier**: ต้องจับคู่ให้ถูก `int -> %d`, `float -> %f`, `char -> %c` (มีน้องๆ หลายคนชอบจำสลับ)
*   **การหารจำนวนเต็ม**: ในภาษา C ถ้าเอา `int` / `int` ผลลัพธ์จะโดน "ปัดเศษทิ้ง" ทันที (เช่น `10 / 3` ได้ `3` ไม่ใช่ `3.33`) ถ้าอยากได้ทศนิยม ต้องมีอย่างน้อยตัวนึงที่เป็น `float` (เช่น `10.0 / 3`)
*   **Modulo (`%`)**: คือการหารเอาเศษ ใช้บ่อยมากในการเช็คเลขคู่เลขคี่ (`x % 2 == 0`)

### ⚠️ ข้อผิดพลาดที่มือใหม่มักเจอ (Common Pitfalls)
*   **ใช้ `%f` ปรินต์ค่า `int` หรือสลับกัน**: ผลลัพธ์จะออกมาเป็นเลขขยะ (Garbage value) หรือ 0.0000 
*   **เครื่องหมายตัวอักษร**: `char` ต้องใช้ **Single Quote (`'A'`)** เท่านั้น ถ้าใช้ Double Quote (`"A"`) มันจะมองเป็น String แล้วจะ error หรือได้ผลแปลกๆ ตอนรัน

## 📖 บทที่ 3: Flow Control

### 🎯 จุดประสงค์
ให้นักเรียนรู้จักการใช้เงื่อนไข (Conditions) เพื่อให้โปรแกรมตัดสินใจ และการวนลูป (Loops) เพื่อทำซ้ำ

### 💡 สิ่งที่ต้องเน้น (Key Points)
*   **เช็คเท่ากับใช้ `==`**: การกำหนดค่าใช้ `=` (ตัวเดียว) แต่ถ้าเช็คเงื่อนไขว่าเท่ากันไหมใช้ `==` (สองตัว)
*   **ลำดับของ `if-else if`**: โปรแกรมจะเช็คจากบนลงล่าง อันไหนเป็นจริงก่อน มันจะทำอันนั้นแล้วจบเลย (เช่น ถ้าเช็คเกรด ต้องเช็คคะแนนสูง (>= 80) ก่อนคะแนนต่ำ (>= 50))
*   **ความต่างของ `while` กับ `for`**: 
    *   `while` เหมาะกับตอนที่ "ไม่รู้จำนวนรอบเป๊ะๆ" แต่มีเงื่อนไขหยุด
    *   `for` เหมาะกับตอนที่ "รู้จำนวนรอบที่แน่นอน" (นับ 1 ถึง 10)

### ⚠️ ข้อผิดพลาดที่มือใหม่มักเจอ (Common Pitfalls)
*   **ใส่ Semicolon หลัง if หรือ for**: 
    *   `if (score >= 50); { printf("Pass"); }` แบบนี้โปรแกรมจะพิมพ์ Pass ตลอด เพราะถือว่า if จบไปแล้วที่ `;`!
*   **ใช้ `=` แทน `==` ใน if**: 
    *   `if (money = 100)` แบบนี้เงื่อนไขจะเป็นจริงเสมอ และ money จะกลายเป็น 100 ทันที
*   **Infinite Loop ใน while**: ลืมเพิ่ม/ลดค่าตัวแปร (เช่น ลืม `i++;`) ทำให้โปรแกรมค้างอยู่ในลูปตลอดกาล (ใน Colab ต้องสอนวิธีกด Stop/Interrupt Execution ให้เด็กๆ ด้วย)

## 📖 บทที่ 4: Arrays and Functions

### 🎯 จุดประสงค์
ให้นักเรียนรู้จักโครงสร้างข้อมูลพื้นฐาน (Array 1 มิติ) และการเขียนฟังก์ชันเพื่อลดความซ้ำซ้อนของโค้ด

### 💡 สิ่งที่ต้องเน้น (Key Points)
*   **Array Index เริ่มที่ 0**: ถ้า Array มี 5 ช่อง ช่องแรกคือ `[0]` ช่องสุดท้ายคือ `[4]`
*   **การวนลูปกับ Array**: มักจะใช้ `for(int i=0; i<5; i++)` คู่กันเสมอ
*   **ฟังก์ชัน**: 
    *   ถ้าฟังก์ชันทำแค่แสดงผล ให้คืนค่าเป็น `void`
    *   ถ้ามีการคำนวณแล้วส่งผลกลับ ต้องใช้ `return` และระบุ Type เช่น `int` หรือ `float`

### ⚠️ ข้อผิดพลาดที่มือใหม่มักเจอ (Common Pitfalls)
*   **Array Out of Bounds**: เข้าถึง Index ที่ไม่มีอยู่จริง เช่น Array มี 5 ช่อง แต่ไปสั่งปรินต์ `scores[5]` ซึ่งก็คือช่องที่ 6! ในภาษา C มันจะไม่ฟ้อง Error ตอนคอมไพล์ แต่จะดึงเอาเลขขยะมาแสดงผล หรืออาจจะทำให้โปรแกรมแครชได้เลย
*   **ลืมประกาศ Prototype หรือเขียนฟังก์ชันไว้ล่าง `main()`**: ถ้านักเรียนเขียนฟังก์ชันไว้ด้านล่างของ `main` โดยไม่ได้ประกาศ Prototype ไว้ข้างบน คอมไพเลอร์ของ C จะมองไม่เห็นแล้วพ่น Warning/Error ออกมา (แนะนำให้สอนเขียนฟังก์ชันไว้ **บน** `main` เสมอในคลาสนี้เพื่อความง่าย)
*   **ลืม `return` ในฟังก์ชัน**: ถ้าฟังก์ชันเป็น `int` แต่ลืม `return` ค่า บางทีมันก็รันผ่านแต่มันจะส่งค่าขยะ (Garbage) กลับไป

### 🎉 สรุปคำแนะนำเพิ่มเติมในการสอน (Teaching Tips)
1. **รันโค้ดบ่อยๆ**: กระตุ้นให้นักเรียนแก้โค้ดทีละนิดแล้วลองรันเลย จะได้เห็นภาพว่าสิ่งที่แก้ส่งผลยังไง
2. **อย่ากลัว Error**: เวลาน้องๆ พิมพ์ผิดแล้วเจอ Error แดงเถือกใน Colab ให้สอนวิธีอ่าน Error (เช่น ดูบรรทัด ดูข้อความ `expected ';' before ...`) จะช่วยให้น้องช่วยเหลือตัวเองได้เก่งขึ้น
3. **การพิมพ์**: ย้ำเรื่องตัวพิมพ์เล็ก/พิมพ์ใหญ่ในภาษา C (Case-sensitive) `Main` ไม่เหมือน `main`, `Printf` ไม่เหมือน `printf`
