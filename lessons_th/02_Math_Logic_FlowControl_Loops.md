## การคำนวณทางคณิตศาสตร์
ภาษา C รองรับเครื่องหมายคณิตศาสตร์พื้นฐาน:
- บวก `+`
- ลบ `-`
- คูณ `*` 
- หาร `/`
- หารเอาเศษ `%` (Modulus นิยมใช้หาเลขคู่/คี่)

> **ข้อควรระวัง:** การหารเลขจำนวนเต็ม (`int` / `int`) จะ **ปัดเศษทิ้งเสมอ** เช่น `5 / 2` คอมพิวเตอร์จะตอบว่า `2` (ไม่ใช่ 2.5) ถ้าต้องการผลลัพธ์เป็นทศนิยม ต้องมีตัวใดตัวหนึ่งเป็นข้อมูลชนิด `float`

**แนวปฏิบัติที่ดี:** ในการคำนวณ เราควรนำค่าที่คำนวณได้ไปเก็บไว้ในตัวแปรใหม่ก่อน แล้วจึงนำตัวแปรใหม่ไปแสดงผล เพื่อให้โค้ดเป็นระเบียบและอ่านง่าย

```c
#include <stdio.h>

int main() {
    int a = 10;
    int b = 3;
    
    // คำนวณแล้วเก็บผลลัพธ์ไว้ในตัวแปรใหม่
    int sum = a + b;
    int difference = a - b;
    int quotient = a / b;
    int remainder = a % b;
    
    printf("10 + 3 = %d\n", sum);
    printf("10 - 3 = %d\n", difference);
    printf("10 / 3 = %d (การหาร int ได้ผลลัพธ์แบบปัดเศษทิ้ง)\n", quotient);
    printf("10 %% 3 = %d (ใช้หาเศษจากการหาร)\n", remainder); // พิมพ์ %% เพื่อแสดงเครื่องหมาย %
    return 0;
}
```

### แบบฝึกหัด 2.1: เครื่องคิดเลขคูณเลข
รับตัวเลข 2 ตัว (ใช้ `scanf`) จากนั้นคำนวณผลคูณ เก็บไว้ในตัวแปรใหม่ แล้วแสดงผลลัพธ์ออกมา

```text
Enter number 1: 5
Enter number 2: 4
Result: 20
```

### แบบฝึกหัด 2.2: หาพื้นที่สี่เหลี่ยมผืนผ้า
รับค่า ความกว้าง (width) และ ความยาว (length) เก็บลงตัวแปรชนิดทศนิยม คำนวณหาพื้นที่ (กว้าง x ยาว) แล้วแสดงผลลัพธ์ 

### แบบฝึกหัด 2.3: แม่ค้าทอนเงิน
สมมติว่าซื้อสินค้าชิ้นหนึ่งราคา 35 บาท และผู้ใช้จ่ายแบงค์ 100 ให้เขียนโปรแกรมคำนวณเงินทอนเก็บไว้ในตัวแปร แล้วแสดงจำนวนเงินที่ต้องทอน

# บทที่ 3: การควบคุมทิศทางโปรแกรม (Flow Control)

โดยปกติโปรแกรมจะทำงานเรียงจากบรรทัดบนลงล่าง แต่เราสามารถควบคุมทิศทางให้โปรแกรม "เลือกตัดสินใจ" หรือ "ทำซ้ำ" ได้

## เงื่อนไข if - else if - else
ใช้ในการตรวจสอบเงื่อนไข หากเงื่อนไขเป็นจริง (True) โปรแกรมจะเข้าไปทำงานในปีกกานั้น

เครื่องหมายสำหรับเปรียบเทียบ:
- `==` เท่ากับ 
- `!=` ไม่เท่ากับ
- `>` มากกว่า
- `<` น้อยกว่า
- `>=` มากกว่าหรือเท่ากับ
- `<=` น้อยกว่าหรือเท่ากับ

```c
#include <stdio.h>

int main() {
    int money = 50;
    
    // โปรแกรมจะตรวจสอบจากบนลงล่าง หากเจอเงื่อนไขที่เป็นจริง จะทำงานแล้วจบเงื่อนไขทันที
    if (money >= 100) {
        printf("กินชาบู\n");
    } else if (money >= 50) {
        printf("กินกะเพรา\n");
    } else {
        printf("กินมาม่า\n");
    }
    return 0;
}
```

### แบบฝึกหัด 3.1: เครื่องตัดเกรด
รับคะแนน 1 ตัว (int)
- ถ้าคะแนน >= 80 ได้เกรด A
- ถ้าคะแนน >= 70 ได้เกรด B
- ถ้าคะแนน >= 60 ได้เกรด C
- ถ้าคะแนน >= 50 ได้เกรด D
- ถ้าคะแนน < 50 ได้เกรด F
*เพิ่มเงื่อนไขพิเศษ:* ถ้ากรอกคะแนนมาเกิน 100 ให้แสดงข้อความว่า 'Cheating!'

### แบบฝึกหัด 3.2: ตรวจสอบเลขคู่/คี่
รับตัวเลข 1 ตัว แล้วให้โปรแกรมบอกว่ามันคือ "Even" (เลขคู่) หรือ "Odd" (เลขคี่)
*(คำใบ้: เลขคู่คือเลขที่หาร 2 แล้วเหลือเศษ 0 สามารถใช้เครื่องหมาย `%` ช่วยตรวจสอบได้)*

## การทำซ้ำ (Loops)
ใช้ในการสั่งให้โปรแกรมทำงานชุดเดิมซ้ำๆ ตามเงื่อนไขที่กำหนด 

### While Loop (ทำซ้ำตราบเท่าที่เงื่อนไขยังเป็นจริง)
เหมาะสำหรับกรณีที่เราไม่รู้จำนวนรอบที่แน่ชัด

```c
#include <stdio.h>

int main() {
    int i = 0; // กำหนดจุดเริ่มต้น
    
    while (i < 5) { // ตรวจสอบเงื่อนไข
        printf("%d\n", i);
        i++; // สำคัญ: ต้องมีการอัปเดตค่าเสมอ มิฉะนั้นลูปจะไม่จบการทำงาน (Infinity Loop)
    }
    return 0;
}
```

### For Loop (ทำซ้ำแบบกำหนดจำนวนรอบได้ชัดเจน)
รวบรวมการตั้งจุดเริ่มต้น, เงื่อนไข, และการเปลี่ยนแปลงค่า ไว้ในบรรทัดเดียวกัน

```c
#include <stdio.h>

int main() {
    // for (เริ่มต้น ; ตรวจสอบเงื่อนไข ; อัปเดตค่า)
    for (int i = 5; i > 0; i--) {
        printf("เหลือเวลา %d วินาที\n", i);
    }
    printf("หมดเวลา!\n");
    return 0;
}
```

### แบบฝึกหัด 3.3: โปรแกรมสูตรคูณ
รับแม่สูตรคูณ 1 ตัว แล้วใช้ Loop พิมพ์สูตรคูณแม่นั้นตั้งแต่คูณ 1 ถึง 12
ตัวอย่าง:
```text
Enter number: 2
2 x 1 = 2
2 x 2 = 4
...
2 x 12 = 24
```

### แบบฝึกหัด 3.4: พิมพ์ดวงดาว
รับตัวเลข `N` 1 ตัว แล้วใช้ Loop พิมพ์เครื่องหมาย `*` ติดกันจำนวน `N` ดวง 
(เช่น หากผู้ใช้พิมพ์เลข 5 จะแสดงผลเป็น `*****`)
