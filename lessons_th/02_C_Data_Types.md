# บทที่ 2: ชนิดข้อมูล (Data Types) และ ตัวแปร (Variables)

ตัวแปร (Variables) คือพื้นที่ในหน่วยความจำที่เราจองไว้เพื่อเก็บข้อมูล โดยเราต้องกำหนดชนิดของข้อมูลให้ถูกต้อง เพื่อให้คอมพิวเตอร์จัดสรรพื้นที่ได้อย่างเหมาะสม

## ชนิดข้อมูลพื้นฐานในภาษา C
- `int` (Integer) ใช้เก็บ **จำนวนเต็ม** (เช่น 5, -10, 1000)
- `float` (Floating point) ใช้เก็บ **ตัวเลขทศนิยม** (เช่น 3.14, -0.01)
- `char` (Character) ใช้เก็บ **ตัวอักษร 1 ตัว** (ครอบด้วยเครื่องหมาย `' '` เช่น `'A'`, `'z'`)

| ชนิดข้อมูล | ขนาดหน่วยความจำ | ขอบเขตข้อมูล (โดยประมาณ) |
| --- | --- | --- |
| `int` | 4 bytes | -2,147,483,648 ถึง 2,147,483,647 |
| `float` | 4 bytes | ทศนิยมประมาณ 6-7 ตำแหน่ง |
| `char` | 1 byte | อักขระ 1 ตัว |

### กฎการตั้งชื่อตัวแปร
1. ห้ามเว้นวรรค (สามารถใช้ `_` แทนได้ เช่น `my_score`)
2. ห้ามขึ้นต้นด้วยตัวเลข (เช่น `1player` จะทำให้เกิด Error ต้องใช้ `player1`)
3. ห้ามใช้คำสงวนของระบบ (เช่น `int`, `return`, `main`)

ในการใช้ `printf` แสดงค่าตัวแปร เราต้องใช้รหัสให้ตรงกับชนิดข้อมูล (Format Specifier):
- `int` ใช้ `%d`
- `float` ใช้ `%f`
- `char` ใช้ `%c`

```c
#include <stdio.h>

int main() {
    int score = 100;
    float gpa = 3.99;
    char grade = 'A';

    printf("Score: %d\n", score);
    printf("GPA: %.2f\n", gpa); // %.2f หมายถึง แสดงทศนิยม 2 ตำแหน่ง
    printf("Grade: %c\n", grade);
    return 0;
}
```

## การคำนวณทางคณิตศาสตร์
ภาษา C รองรับเครื่องหมายคณิตศาสตร์พื้นฐาน:
- บวก `+`
- ลบ `-`
- คูณ `*` 
- หาร `/`
- หารเอาเศษ `%` (Modulus นิยมใช้หาเลขคู่/คี่)

> **ข้อควรระวัง:** การหารเลขจำนวนเต็ม (`int` / `int`) จะ **ปัดเศษทิ้งเสมอ** เช่น `5 / 2` คอมพิวเตอร์จะตอบว่า `2` (ไม่ใช่ 2.5) ถ้าต้องการผลลัพธ์เป็นทศนิยม ต้องมีตัวใดตัวหนึ่งเป็นข้อมูลชนิด `float`

**แนวปฏิบัติที่ดี:** ในการคำนวณ เราควรนำค่าที่คำนวณได้ไปเก็บไว้ในตัวแปรใหม่ก่อน แล้วจึงนำตัวแปรใหม่ไปแสดงผล เพื่อให้โค้ดเป็นระเบียบและอ่านง่าย

```c
#include <stdio.h>

int main() {
    int a = 10;
    int b = 3;
    
    // คำนวณแล้วเก็บผลลัพธ์ไว้ในตัวแปรใหม่
    int sum = a + b;
    int difference = a - b;
    int quotient = a / b;
    int remainder = a % b;
    
    printf("10 + 3 = %d\n", sum);
    printf("10 - 3 = %d\n", difference);
    printf("10 / 3 = %d (การหาร int ได้ผลลัพธ์แบบปัดเศษทิ้ง)\n", quotient);
    printf("10 %% 3 = %d (ใช้หาเศษจากการหาร)\n", remainder); // พิมพ์ %% เพื่อแสดงเครื่องหมาย %
    return 0;
}
```

### แบบฝึกหัด 2.1: เครื่องคิดเลขคูณเลข
รับตัวเลข 2 ตัว (ใช้ `scanf`) จากนั้นคำนวณผลคูณ เก็บไว้ในตัวแปรใหม่ แล้วแสดงผลลัพธ์ออกมา

```text
Enter number 1: 5
Enter number 2: 4
Result: 20
```

### แบบฝึกหัด 2.2: หาพื้นที่สี่เหลี่ยมผืนผ้า
รับค่า ความกว้าง (width) และ ความยาว (length) เก็บลงตัวแปรชนิดทศนิยม คำนวณหาพื้นที่ (กว้าง x ยาว) แล้วแสดงผลลัพธ์ 

### แบบฝึกหัด 2.3: แม่ค้าทอนเงิน
สมมติว่าซื้อสินค้าชิ้นหนึ่งราคา 35 บาท และผู้ใช้จ่ายแบงค์ 100 ให้เขียนโปรแกรมคำนวณเงินทอนเก็บไว้ในตัวแปร แล้วแสดงจำนวนเงินที่ต้องทอน
