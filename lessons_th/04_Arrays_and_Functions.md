## Arrays (ชุดข้อมูล)
หากเราต้องการเก็บคะแนนสอบของนักเรียน 50 คน การสร้างตัวแปรแยกกัน 50 ตัวแปรคงไม่ใช่วิธีที่ดีนัก เราสามารถใช้ **Array** เพื่อเก็บข้อมูลประเภทเดียวกันหลายๆ ค่าไว้ภายใต้ชื่อตัวแปรเดียวได้ โดยจะมีการระบุตำแหน่งของข้อมูลด้วย "หมายเลข Index"

> **ข้อสังเกตที่สำคัญ:** หมายเลข Index ของ Array **เริ่มต้นที่ 0 เสมอ** (ข้อมูลตัวแรกจะอยู่ที่ Index 0)

```c
#include <stdio.h>

int main() {
    // สร้าง Array ชื่อ scores เก็บข้อมูลชนิด int จำนวน 5 ค่า
    int scores[5] = {10, 20, 30, 40, 50};
    
    printf("คะแนนคนที่ 1 (Index 0): %d\n", scores[0]);
    printf("คะแนนคนที่ 5 (Index 4): %d\n", scores[4]);
    
    // เรานิยมใช้ For Loop ร่วมกับ Array เพื่อเข้าถึงข้อมูลทุกตัว
    for(int i = 0; i < 5; i++) {
        printf("คะแนนคนที่ %d: %d\n", i+1, scores[i]);
    }
    return 0;
}
```

### การสร้าง String (ข้อความ) ด้วย Array ของ Char
ในภาษา C จะไม่มีตัวแปรประเภท String (ข้อความ) โดยตรง แต่เราสามารถนำตัวแปร `char` (ที่ปกติเก็บตัวอักษรได้แค่ 1 ตัว) มาเรียงต่อกันเป็น Array เพื่อเก็บข้อความยาวๆ ได้

```c
#include <stdio.h>

int main() {
    // จองพื้นที่ 20 ช่องสำหรับเก็บข้อความ (รวมช่องว่างและตัวอักษรพิเศษ \0 ที่ใช้ปิดท้าย String)
    char name[20]; 
    
    printf("Enter your name: ");
    // การรับค่า String ด้วย scanf ไม่ต้องใส่ & นำหน้าตัวแปร
    scanf("%s", name); 
    
    // เวลาแสดงผล String เราจะใช้ %s
    printf("Welcome, %s!\n", name);
    return 0;
}
```

## ฟังก์ชัน (Functions)
เมื่อโปรแกรมมีขนาดใหญ่ขึ้น การเขียนคำสั่งทั้งหมดไว้ใน `main` จะทำให้โค้ดดูซับซ้อน เราจึงแยกโค้ดบางส่วนออกเป็น **ฟังก์ชัน** เพื่อความเป็นระเบียบและสามารถเรียกซ้ำได้

```c
#include <stdio.h>

// 1. ฟังก์ชันแบบ "ไม่คืนค่า" (ระบุชนิดเป็น void)
// ใช้เมื่อต้องการให้ฟังก์ชันทำงานบางอย่างให้เสร็จสิ้นโดยไม่ต้องส่งค่ากลับมา
void say_hello() {
    printf("Hello CBC!\n");
}

// 2. ฟังก์ชันแบบ "คืนค่า" (ระบุชนิดข้อมูล เช่น int)
// ใช้เมื่อต้องการให้ฟังก์ชันคำนวณและส่งผลลัพธ์กลับมาให้โปรแกรมหลักใช้งานต่อ
int add(int a, int b) {
    int result = a + b;
    return result; // คืนค่าผลลัพธ์กลับไป
}

int main() {
    say_hello(); // เรียกใช้งานฟังก์ชัน say_hello
    
    // เรียกใช้งานฟังก์ชัน add โดยส่งค่า 5 และ 7 ไป
    // และสร้างตัวแปร sum มารอรับค่าที่ฟังก์ชันส่งกลับมา
    int sum = add(5, 7); 
    
    printf("5 + 7 = %d\n", sum);
    
    return 0;
}
```

### แบบฝึกหัด 4.3: ฟังก์ชันทวีคูณ (Double It!)
สร้างฟังก์ชันชื่อ `double_number` ที่รับค่าตัวเลข (int) 1 ตัว แล้วทำการคูณ 2 จากนั้นคืนค่ากลับมาเพื่อแสดงผลใน `main`

### แบบฝึกหัด 4.4: ฟังก์ชันตรวจสอบผ่าน/ตก
สร้างฟังก์ชันชื่อ `check_pass` ที่รับคะแนน 1 ตัว (int)
- ถ้าคะแนน >= 50 ให้คืนค่า 1 (แทนความหมายว่า ผ่าน)
- ถ้าคะแนน < 50 ให้คืนค่า 0 (แทนความหมายว่า ตก)
จากนั้นใน `main` ให้เรียกใช้ฟังก์ชันและแสดงผลลัพธ์
