## ภาษา C คืออะไร?
ภาษา C เป็นภาษาโปรแกรมที่ทำงานได้รวดเร็วและเป็นรากฐานของภาษาใหม่ๆ มากมาย การเขียนโปรแกรมด้วยภาษา C จะต้องผ่านกระบวนการ **Compile** เพื่อแปลงโค้ดที่เราเขียนให้อยู่ในรูปที่คอมพิวเตอร์เข้าใจ (เครื่องมือยอดนิยมคือ GCC Compiler) 

อย่างไรก็ตาม เพื่อความสะดวกในการเรียนรู้ เราจะเขียนและรันโค้ดผ่าน Online Compiler ครับ
> แนะนำให้ใช้ **[Programiz C Online Compiler](https://www.programiz.com/c-programming/online-compiler/)** ควบคู่กับการอ่านเนื้อหานะครับ

## โครงสร้างพื้นฐาน
โครงสร้างหลักของโปรแกรมภาษา C จะมีหน้าตาดังนี้ โค้ดทุกอย่างที่เราต้องการให้คอมพิวเตอร์ทำ จะต้องอยู่ภายใน `main function` เสมอ

```c
#include <stdio.h> // นำเข้าไลบรารีพื้นฐานสำหรับการรับและแสดงผล (Standard Input/Output)

// จุดเริ่มต้นของโปรแกรม
int main() {
    
    // เขียนโค้ดของเราตรงนี้
    
    return 0; // จบการทำงานของฟังก์ชัน main
}
```

> **ข้อควรระวัง:** คำสั่งในภาษา C ส่วนใหญ่ต้องจบด้วยเครื่องหมายเซมิโคลอน `;` เสมอ หากลืมโปรแกรมจะเกิด Error และไม่สามารถทำงานได้

## การแสดงผลด้วย `printf`
เราใช้คำสั่ง `printf` (ย่อมาจาก Print Formatted) เพื่อแสดงข้อความออกทางหน้าจอ

```c
#include <stdio.h>

int main() {
    printf("Hello CBC Boost Camp!\n"); // \n (Backslash n) ใช้สำหรับขึ้นบรรทัดใหม่
    
    printf("My name is ...\n");
    return 0;
}
```

### แบบฝึกหัด 1.1: ทักทายโลกกว้าง
ให้นำโค้ดด้านบนไปรันในเว็บ Programiz แล้ว:
1. เปลี่ยนคำว่า `My name is ...` เป็นชื่อเล่นของตัวเอง
2. เพิ่มคำสั่ง `printf` เพื่อบอกสิ่งที่ชอบกินอีก 1 บรรทัด

## การรับค่าด้วย `scanf`
เราใช้คำสั่ง `scanf` (Scan Formatted) เพื่อรับข้อมูลที่ผู้ใช้พิมพ์เข้ามา

```c
#include <stdio.h>

int main() {
    int age; // สร้างตัวแปรมารอรับค่าอายุ (เป็นตัวเลขจำนวนเต็ม)
    
    printf("How old are you?: "); 
    
    // สำหรับ scanf ต้องมี & (Ampersand) นำหน้าชื่อตัวแปร เพื่อชี้ที่อยู่ของข้อมูล
    scanf("%d", &age); 
    
    printf("Wow, you are %d years old!\n", age);
    return 0;
}
```

### แบบฝึกหัด 1.2: เครื่องคิดเลขคำนวณปีเกิด
เขียนโปรแกรมถาม **ปีเกิด (ค.ศ.)** แล้วให้คอมพิวเตอร์ **คำนวณอายุ** ออกมา 
*(ใบ้ให้: สร้างตัวแปรรับปีเกิด แล้วนำ `2026 - ปีเกิด` ไปแสดงผล)*

### แบบฝึกหัด 1.3: แฟ้มประวัติส่วนตัว
เขียนโปรแกรมถาม "อายุ" และ "น้ำหนัก" (รับเป็นตัวเลขจำนวนเต็ม) แล้วให้โปรแกรมแสดงผลสรุปออกมาพร้อมกัน 
ตัวอย่าง:
```text
Enter your age: 15
Enter your weight: 55
You are 15 years old and your weight is 55!
```
