## 📝 โครงสร้างพื้นฐานของภาษา C
ภาษา C จะมีโครงสร้างหลักๆ ที่เปรียบเสมือน "ร่างกาย" ของมัน ถ้าขาดไปโปรแกรมจะไม่ทำงานเลยครับ โค้ดทุกอย่างที่เราอยากให้คอมพิวเตอร์ทำ จะเริ่มทำงานจาก `main function` 

```c
// บรรทัดนี้เหมือนการหยิบ "กล่องเครื่องมือ" พื้นฐานมาใช้งาน (Standard Input/Output)
#include <stdio.h> 

// นี่คือจุดเริ่มต้นของโปรแกรม! คอมพิวเตอร์จะวิ่งเข้ามาหาคำว่า main() ก่อนเสมอ
int main() {
    
    // โค้ดของเราจะอยู่ในปีกกานี้แหละ!
    
    return 0; // จบโปรแกรมแบบสวยงาม (บอกระบบว่าทำงานเสร็จสมบูรณ์ ไม่มี error)
}
```

> ⚠️ **ข้อควรระวังสุดฮิต:** โค้ดในภาษา C เกือบทุกบรรทัด **ต้องจบด้วยเครื่องหมายเซมิโคลอน `;`** เสมอ! ลืมปุ๊บ พังปั๊บเตือนไว้ก่อนเลยนะ!

## 🖨️ การแสดงผลด้วย `printf`
อยากให้คอมพิวเตอร์พูดอะไรบนหน้าจอ? ใช้คำสั่ง `printf` (ย่อมาจาก Print Formatted) ได้เลย!

```c
#include <stdio.h>

int main() {
    // พิมพ์ข้อความในเครื่องหมายอัญประกาศ "..."
    printf("Hello CBC Boost Camp!\n"); // \n (Backslash n) คือการสั่งขึ้นบรรทัดใหม่
    
    printf("My name is ...\n");
    return 0;
}
```

แล้วกดปุ่ม **Run** เลย!

## 📥 การรับค่าด้วย `scanf`
เวลาเราอยากให้ผู้ใช้ (User) "พิมพ์" ข้อมูลเข้ามาให้โปรแกรม เราจะใช้คำสั่ง `scanf` (Scan Formatted) 

```c
#include <stdio.h>

int main() {
    int age; // สร้างกล่องเปล่าๆ มารอรับค่าอายุ (เป็นตัวเลข)
    
    printf("How old are you?: "); // ถามผู้ใช้ก่อน (ไม่ต้องใส่ \n จะได้พิมพ์ต่อท้ายได้)
    
    // สำคัญมาก! สำหรับ scanf ต้องมี & (Ampersand) นำหน้าชื่อตัวแปรเสมอ เพื่อชี้เป้าหมายที่อยู่ของกล่อง
    scanf("%d", &age); 
    
    printf("Wow, you are %d years old!\n", age);
    return 0;
}
```

### 🎯 แบบฝึกหัด 1.2: เครื่องคิดเลขคำนวณปีเกิด
ลองเขียนโค้ดถาม **ปีเกิด (ค.ศ.)** ของเพื่อนข้างๆ แล้วให้คอมพิวเตอร์ **คำนวณอายุ** ออกมาดูสิ!
*(ใบ้ให้: สร้างตัวแปรมารับค่าปีเกิด แล้วเอา `2026 - ปีเกิด` พิมพ์ออกมาได้เลย)*

### 🎯 แบบฝึกหัด 1.3: แฟ้มประวัติส่วนตัว
เขียนโปรแกรมถาม "อายุ" และ "น้ำหนัก" (รับเป็นตัวเลขจำนวนเต็ม) จากนั้นให้โปรแกรมปรินต์สรุปออกมาพร้อมกัน 
ตัวอย่าง:
```text
Enter your age: 15
Enter your weight: 55
You are 15 years old and your weight is 55!
```
