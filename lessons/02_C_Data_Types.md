# 📦 ชนิดข้อมูล (Data Types) และ ตัวแปร (Variables)

ตัวแปร (Variables) ก็เหมือน **'กล่อง'** ที่เอาไว้เก็บข้อมูลครับ ซึ่งกล่องแต่ละใบก็ออกแบบมาเพื่อเก็บของต่างชนิดกัน ถ้าเราเอาน้ำไปใส่กล่องกระดาษมันก็พังใช่ไหมล่ะ? คอมพิวเตอร์ก็เหมือนกันครับ!

- `int` ย่อมาจาก Integer เอาไว้เก็บ **จำนวนเต็ม** (เช่น 5, -10, 1000)
- `float` เอาไว้เก็บ **ตัวเลขทศนิยม** (เช่น 3.14, -0.01)
- `char` ย่อมาจาก Character เอาไว้เก็บ **ตัวอักษร 1 ตัว** (ต้องครอบด้วยเครื่องหมาย `' '` เช่น `'A'`, `'z'`)

### 🪧 กฎการตั้งชื่อกล่อง (ตัวแปร)
1. ห้ามเว้นวรรค (ใช้ `_` แทนได้ เช่น `my_score`)
2. ห้ามขึ้นต้นด้วยตัวเลข (เช่น `1player` แบบนี้พัง! ต้องเป็น `player1`)
3. ห้ามใช้คำสงวนที่คอมพิวเตอร์ใช้ไปแล้ว (เช่น `int`, `return`, `main`)

เวลาจะสั่งให้ `printf` ปรินต์ค่าข้อมูลออกมา เราต้องใช้ **'รหัสลับ (Format Specifier)'** ให้ตรงกับชนิดของข้อมูลด้วยนะ:
- ชนิดข้อมูล `int` ใช้รหัส `%d`
- ชนิดข้อมูล `float` ใช้รหัส `%f`
- ชนิดข้อมูล `char` ใช้รหัส `%c`

```c
#include <stdio.h>

int main() {
    int score = 100;
    float gpa = 3.99;
    char grade = 'A';

    printf("Score: %d\n", score);
    printf("GPA: %.2f\n", gpa); // ทริค: %.2f คือขอให้โชว์ทศนิยมแค่ 2 ตำแหน่ง
    printf("Grade: %c\n", grade);
    return 0;
}
```

## 🧮 การคำนวณทางคณิตศาสตร์
ภาษา C คิดเลขเก่งมาก! เครื่องหมายที่ใช้ได้แก่:
- บวก `+`
- ลบ `-`
- คูณ `*` (ใช้ดอกจันนะ ไม่ใช่ x)
- หาร `/`
- หารเอาเศษ `%` (เรียกว่า Modulus เอาไว้หาเศษที่เหลือจากการหาร มักใช้เช็คเลขคู่เลขคี่)

> ⚠️ **ระวัง! โดนหลอกประจำ!** การหารเลขจำนวนเต็ม (`int` / `int`) จะ **ปัดเศษทิ้งเสมอ!** เช่น `5 / 2` คอมพิวเตอร์จะตอบว่า `2` (ไม่ใช่ 2.5) ถ้าอยากได้ทศนิยม ต้องมีตัวใดตัวหนึ่งเป็นข้อมูล `float` ก่อนนะ

```c
#include <stdio.h>

int main() {
    int a = 10;
    int b = 3;
    
    printf("10 + 3 = %d\n", a + b);
    printf("10 - 3 = %d\n", a - b);
    printf("10 / 3 = %d (อ้าว เศษหายไปไหน? นี่ไงการหาร int!)\n", a / b);
    printf("10 %% 3 = %d (อยู่นี่ไงเศษ! เราใช้ Modulus)\n", a % b); // ต้องพิมพ์ %% สองตัวเพื่อปรินต์เครื่องหมาย %
    return 0;
}
```

### 🎯 แบบฝึกหัด 2.1: เครื่องคิดเลขคูณเลข
รับค่าตัวเลข 2 ตัว (ใช้ `scanf` สองรอบ หรือรับทีเดียว `%d %d` ก็ได้) จากนั้นให้โปรแกรมแสดงผลการ **คูณ** ของสองตัวนี้

```text
Enter number 1: 5
Enter number 2: 4
Result: 20
```
