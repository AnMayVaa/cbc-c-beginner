# 📚 อาร์เรย์ (Arrays) และ ฟังก์ชัน (Functions)

## 📦 Arrays (ขบวนรถไฟเก็บข้อมูล)
ลองนึกภาพว่าเรามีคะแนนสอบของนักเรียน 50 คน ถ้าต้องสร้างตัวแปร `score1`, `score2` ไปจนถึง `score50` คงเหนื่อยแย่! 
เราจึงใช้ **Array** ซึ่งเปรียบเสมือน "ขบวนรถไฟ" ที่ตู้กี้แต่ละตู้เก็บข้อมูลประเภทเดียวกันได้ และเราสามารถระบุตู้ได้ด้วย "หมายเลข Index"

> ⚠️ **กฎเหล็กของโปรแกรมเมอร์:** หมายเลข Index ของ Array **"เริ่มต้นที่ 0 เสมอ!"** (ตู้แรกคือตู้เบอร์ 0)

```c
#include <stdio.h>

int main() {
    // สร้างรถไฟชื่อ scores มี 5 ตู้ (เก็บเลขจำนวนเต็ม)
    int scores[5] = {10, 20, 30, 40, 50};
    
    printf("คะแนนคนที่ 1 (ตู้เบอร์ 0): %d\n", scores[0]);
    printf("คะแนนคนที่ 5 (ตู้เบอร์ 4): %d\n", scores[4]);
    
    // ใช้ for loop วนเปิดดูทีละตู้สบายมาก!
    for(int i = 0; i < 5; i++) {
        printf("คะแนนคนที่ %d: %d\n", i+1, scores[i]);
    }
    return 0;
}
```

### 🎯 แบบฝึกหัด 4.1: เครื่องคิดเงินรวม
รับตัวเลขราคาสินค้า 5 ชิ้นเก็บลง Array จากนั้นใช้ for loop นำตัวเลขทั้งหมดมาบวกกัน แล้วปรินต์ผลรวมออกมา

### 🎯 แบบฝึกหัด 4.2: หาค่าเฉลี่ย
ทำต่อจากข้อ 4.1 ให้นำผลรวมมาหาร 5.0 เพื่อหา 'ค่าเฉลี่ย' (ระวังเรื่องการหารให้ดีล่ะ ต้องได้ทศนิยมนะ!)

## 🛠️ ฟังก์ชัน (Functions)
เวลาโค้ดเราเริ่มยาว การเขียนทุกอย่างยัดไว้ใน `main` จะทำให้ดูยากมาก เราสามารถแยกโค้ดเป็นส่วนย่อยๆ เรียกว่า **ฟังก์ชัน** เพื่อให้เรียกใช้ง่ายขึ้น เป็นระเบียบ และนำกลับมาใช้ใหม่ได้หลายรอบ

```c
#include <stdio.h>

// 1. ฟังก์ชันแบบ "ไม่คืนค่า" (ใช้คำว่า void)
// เหมาะสำหรับฟังก์ชันที่แค่ทำตามสั่งแล้วจบไป เช่น สั่งให้ปรินต์ข้อความ
void say_hello() {
    printf("Hello CBC! 👋\n");
}

// 2. ฟังก์ชันแบบ "คืนค่า" (ระบุชนิดข้อมูล เช่น int)
// เหมาะสำหรับฟังก์ชันที่รับค่าไปคำนวณ แล้วต้องส่งผลลัพธ์กลับมาให้เราใช้ต่อ
int add(int a, int b) {
    int result = a + b;
    return result; // ส่งค่า result กลับไปให้คนเรียก
}

int main() {
    say_hello(); // เรียกใช้ปุ๊บ ทำงานปั๊บ
    
    // เรียกใช้ฟังก์ชัน add ส่ง 5 กับ 7 ไปให้ มันจะ return 12 กลับมา
    // เราต้องเอาตัวแปร (sum) มารับค่า 12 นั้นไว้
    int sum = add(5, 7); 
    printf("5 + 7 = %d\n", sum);
    
    return 0;
}
```

### 🎯 แบบฝึกหัด 4.3: ฟังก์ชันทวีคูณ (Double It!)
สร้างฟังก์ชันชื่อ `double_number` ที่รับค่าตัวเลข (int) 1 ตัว แล้วทำการ **คูณ 2** จากนั้น return ค่ากลับมาให้ `main` ปรินต์

### 🎯 แบบฝึกหัด 4.4: ฟังก์ชันเช็คผ่าน/ตก
สร้างฟังก์ชันชื่อ `check_pass` ที่รับคะแนน 1 ตัว (int)
- ถ้าคะแนน >= 50 ให้ return 1 (แทนความหมายว่า จริง/ผ่าน)
- ถ้าคะแนน < 50 ให้ return 0 (แทนความหมายว่า เท็จ/ตก)
จากนั้นใน main ให้ลองเรียกใช้และปรินต์ผลลัพธ์ดู
