# 🚦 การควบคุมทิศทางโปรแกรม (Flow Control)

บางครั้งเราอยากให้โปรแกรม 'คิดตัดสินใจ' ว่าจะไปทางซ้ายหรือขวา หรืออยากให้ 'ทำซ้ำๆ' ขี้เกียจเขียนโค้ดใหม่ นี่คือบทที่เราจะได้ใช้พลังของคอมพิวเตอร์อย่างแท้จริง!

## 🧐 เงื่อนไข if - else if - else
เราสามารถสั่งโปรแกรมได้ว่า "ถ้า (if) เกิดสิ่งนี้ ให้ทำแบบนี้... ไม่งั้นถ้า (else if) เป็นแบบนี้ล่ะ... ไม่งั้น (else) ก็ทำแบบนี้ไปเลยละกัน!"

เครื่องหมายสำหรับเปรียบเทียบ (ใช้ในวงเล็บ `if`):
- `==` เท่ากับไหม? (สังเกตว่ามีเท่ากับ 2 ตัวนะ! ตัวเดียวเอาไว้จับยัดใส่กล่อง)
- `!=` ไม่เท่ากับ
- `>` มากกว่า
- `<` น้อยกว่า
- `>=` มากกว่าหรือเท่ากับ
- `<=` น้อยกว่าหรือเท่ากับ

```c
#include <stdio.h>

int main() {
    int money = 50;
    
    // โปรแกรมจะเช็คเงื่อนไขจากบนลงล่าง อันไหนจริงก่อน ก็ทำอันนั้นแล้วจบเลย!
    if (money >= 100) {
        printf("กินชาบู!\n");
    } else if (money >= 50) {
        printf("กินกะเพรา\n");
    } else {
        printf("กินมาม่า\n");
    }
    return 0;
}
```

### 🎯 แบบฝึกหัด 3.1: เครื่องตัดเกรด
รับค่าคะแนน 1 ตัว (int)
- ถ้าคะแนน >= 80 ได้เกรด A
- ถ้าคะแนน >= 70 ได้เกรด B
- ถ้าคะแนน >= 60 ได้เกรด C
- ถ้าคะแนน >= 50 ได้เกรด D
- ถ้าคะแนน < 50 ได้เกรด F
*ภารกิจลับ แฮกเกอร์:* ถ้าผู้ใช้กรอกคะแนน > 100 ให้โปรแกรมจับโป๊ะและปรินต์ว่า 'Cheating!'

### 🎯 แบบฝึกหัด 3.2: สแกนเนอร์เลขคู่เลขคี่
รับตัวเลข 1 ตัว แล้วให้โปรแกรมบอกว่ามันคือ "Even" (เลขคู่) หรือ "Odd" (เลขคี่)
*(คำใบ้: เลขคู่คือเลขที่หาร 2 แล้วเหลือเศษ 0 ลองใช้ `%` ดูสิ!)*

## 🔄 การทำซ้ำ (Loops)
ขี้เกียจพิมพ์ `printf` ร้อยรอบหรอ? ใช้ Loop สิ! คอมพิวเตอร์เกิดมาเพื่อทำสิ่งซ้ำๆ โดยไม่บ่นครับ

### While Loop (ทำไปเรื่อยๆ ตราบใดที่เงื่อนไขยังเป็นจริง)
เหมาะกับสถานการณ์ที่เราไม่รู้แน่ชัดว่าจะต้องทำกี่รอบ (เช่น ให้ผู้ใช้ทายรหัสผ่านจนกว่าจะถูก)

```c
#include <stdio.h>

int main() {
    int i = 0; // ตั้งจุดเริ่มต้น
    while (i < 5) { // เช็คว่า i ยังน้อยกว่า 5 ใช่ไหม?
        printf("%d\n", i);
        i++; // สำคัญมาก!! i++ คือการบวกค่า i ทีละ 1 ถ้าลืมบรรทัดนี้ลูปจะรันไม่จบ (Infinity Loop) เครื่องค้างแน่นอน!
    }
    return 0;
}
```

### For Loop (รู้จำนวนรอบที่ชัดเจน)
เอาทุกอย่างมากองรวมกันในบรรทัดเดียวเลย! เหมาะมากถ้ารู้ว่าต้องทำกี่รอบ

```c
#include <stdio.h>

int main() {
    // for (ตั้งจุดเริ่มต้น ; เช็คเงื่อนไข ; การเปลี่ยนแปลงในแต่ละรอบ)
    for (int i = 5; i > 0; i--) {
        printf("เหลือเวลา %d วินาที\n", i);
    }
    printf("ตู้ม!\n");
    return 0;
}
```

### 🎯 แบบฝึกหัด 3.3: ลูปสูตรคูณ
รับค่าแม่สูตรคูณ 1 ตัว แล้วปรินต์สูตรคูณแม่นั้นตั้งแต่ x1 ถึง x12
ตัวอย่าง:
```text
Enter number: 2
2 x 1 = 2
2 x 2 = 4
...
2 x 12 = 24
```

### 🎯 แบบฝึกหัด 3.4: พิมพ์ดาวตามสั่ง
รับค่าตัวเลข `N` มา 1 ตัว แล้วให้ลูปปรินต์ดาว `*` ติดกันจำนวน `N` ดวง 
(เช่น รับเลข 5 ก็ให้ปรินต์ `*****`)
