# 🚀 Computer Boost Camp: C Beginner

ยินดีต้อนรับน้องๆ เข้าสู่ค่าย **Computer Boost Camp** โหมด **C Beginner**! 🎉  
Repository นี้รวบรวมเอกสารการสอนภาษา C แบบเข้าใจง่ายๆ สไตล์ชิลๆ เน้นให้น้องๆ ได้ลองรันและแก้โค้ดไปพร้อมๆ กัน

## 🛠️ วิธีการเรียน

เพื่อความง่ายที่สุดในการเริ่มต้น ให้น้องๆ เปิดเว็บ **[Programiz C Online Compiler](https://www.programiz.com/c-programming/online-compiler/)** คู่ขนานไปกับการอ่านเนื้อหานะครับ 

เมื่อน้องๆ อ่านเนื้อหาและเจอ **"โจทย์แบบฝึกหัด"** ให้สลับหน้าจอไปพิมพ์โค้ดลงในเว็บ Programiz และกดปุ่ม Run ได้เลยทันที! ไม่ต้องกังวลเรื่องการติดตั้งโปรแกรมในเครื่องให้วุ่นวาย
